# 《刀影江湖》青锋剑客·破空刺 (非强化重塑版) 动作帧与实机设计全案

> **招式 ID**：`QF-1`  
> **招式名称**：破空刺（Piercing Void Thrust · 瞬透飞身刺 · 常态版）  
> **设计基准**：**60 FPS** · 2D 横版纯运动学物理 · 统一画布 $680 \times 480\ \text{px}$ (PPU 214)  
> **与重刺的核心本质区别**：
> - **重刺 (`A_H`)**：**“正面重炮·力沉千钧”** —— 双足实踏地面，16 帧长蓄力沉腰推刺，刺到敌人身前停住，击碎盾牌与霸体，产生沉重金属撞击。
> - **破空刺 (`QF-1`)**：**“错身飞刃·瞬透敌后”** —— 4 帧极速前掠，人剑合一贴地掠飞，**化作青白电芒直接穿透敌人身体瞬移至其身后 0.5 米**，背对敌人单膝擦地急刹定格，敌人慢半拍爆出贯穿剑气！

## 3. 视觉语言重构要点对比

```
【重刺】VFX：
          (青锋) ══> ▄███████████> (巨型圆锥气爆/碎石) ──> [撞在敌人胸前停住]
          
【破空刺】VFX：
          (起点) ────────────────────────────── (终点·擦地刹车)
                       [敌人胸口·延迟墨爆]
          特效形态：极细青白激光线 ───┼─── 水墨平切刃 ─── 水墨残影
```

1. **线面极简，锐利如刃**：不再使用圆滚滚的扩散锥，而是采用**极细极亮的青白激光主轴（Core Beam）**与**水墨平切刀锋（Ink Razor）**，强调“以点破面、切断虚空”的高级感。
2. **节奏对比极致化**：
   - 启动极快（5f 瞬间出手）；
   - 突进穿透极快（3f 跨越 1.3 米）；
   - 落地刹车极稳（单膝贴地制动定格）；
   - 伤害反馈延时（慢半拍爆裂），形成教科书级的居合斩杀节奏！
