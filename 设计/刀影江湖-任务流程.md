## 1. 总览

### 1.1 主线任务树

```
序章 PROL（三出身分支）──汇合──▶ 周记茶楼
        │
        ▼
M1-01 废墟余烬 → M1-02 择刃 → M1-03 夜奔官道
        → M1-04 县衙暗火 → M1-05 血刀问罪（赤练）
        → 残谱·页一
        │
        ▼
M2-01 关墙夜 → M2-02 两封信 → M2-03 正邪一纸
        → M2-04 谁先落子（失去一人）→ M2-05 铁壁问关
        → 残谱·页二
        │
        ▼
M3-01 残谱合页 → M3-02 旧皮揭开 → M3-03 北冥之问
        → M3-04 月下决（Boss）→ M3-05 今日开书 → 结局
```

支线可并行；标注「可缺席」的不影响通关，但影响侠名／结局碎片／心法。

### 1.2 通用状态机

`未接 → 已接 → 进行中 → 成功／失败／放弃`

- **成功**：发奖、写江湖录、刷新 NPC 状态。  
- **失败**：部分可重接；关键主线失败＝读档或章节重试点。  
- **放弃**：仅支线；扣「守信」微弱或无（见表）。  
- **互斥**：同组选项任务选一条锁定另一条（如药给官／给匪）。

## 2. 序章任务

### PROL-A　灭门遗孤·余烬

| 项 | 内容 |
|---|---|
| 类型 | 主线／出身 |
| 解锁 | 选出身「灭门遗孤」 |
| 目标 | 逃出剑心堂废墟，抵达清河 |
| 下环 | PROL-MERGE |

**步骤**

| # | 内容 |
|---|---|
| 1 | 废墟拾「染血残角」 |
| 2 | 击败闯入杂兵（教学轻击／闪避） |
| 3 | 面对青衣「表叔」三选一 |
| 4 | 官道伤兵处置 |
| 5 | 抵达清河东郊 |

**详细剧情文案**

【旁白】今夜以前，这里叫剑心堂。今夜以后，它只剩一个字——烬。

（拾残角）

【旁白】老人的手指已硬。纸角却还温——像有人刚刚撕走过更大的秘密。

杂兵甲：「搜！谱呢？小孩呢？」

【选项】「你们是谁的刀？」／「滚。」／（拔刃）

青衣男子：「小兄弟，可是剑心堂的骨血？跟我走——遗产、名分，都有。」

【旁白】伞下的脸很善。善得像一张，专门借给陌生人的皮。

青衣男子：（远去）「通往第一页的火，在清河。」
