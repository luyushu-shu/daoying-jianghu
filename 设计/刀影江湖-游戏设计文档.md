# 《刀影江湖》游戏设计文档

| 项 | 内容 |
|---|---|
| 类型 | 横版动作角色扮演（Side-scrolling ARPG） |
| 题材 | 古典江湖武侠 |
| 视角 | 横版卷轴（首发建议手绘 2D，预留 2.5D） |
| 平台 | PC（键鼠 + 手柄）；主机 / 移动端后置 |
| 商业模式 | 买断；DLC 扩门派与区域；无抽卡、无强制内购 |
| 文档版本 | v1.0（汇总整理） |
| 默认方向 | **章节式单机 ARPG**（非 Roguelite） |

---

## 1. 概述

### 1.1 一句话卖点

在恩怨交织的江湖里，靠**招式节奏**与**门派选择**打出连段、了结恩怨、改写侠名。

### 1.2 体验支柱

| 支柱 | 玩家感受 | 设计落点 |
|---|---|---|
| 打得爽 | 出手有势、受击有反馈、连段可练 | 轻/重取消窗、打击停顿、破招三角 |
| 站得住 | 换门派 / 兵器像换一种玩法 | 每门 1 条不可替换核心机制 |
| 记得住 | 选择会改人、改结局、改江湖评价 | 好感/仇怨、侠名标签、可劝降 Boss |

### 1.3 明确不做（首发）

开放大世界、MMORPG 社交、抽卡养成、以恋爱为主线。

### 1.4 对标与差异

| 参考 | 借什么 | 不借什么 |
|---|---|---|
| 死亡细胞 | 打击节奏、关卡纵深 | Roguelite 每局清空 |
| 影之刃系列 | 华丽连段、技能编排感 | 重度数值与抽卡 |
| 活侠传 | 江湖人物与立场张力 | 纯文字回合为主 |
| 侍魂 / 月华剑士 | 兵器气质、对拼感 | 默认一命街机压迫 |

**差异化：** 横版动作手感 + 中长线江湖关系，用「恩怨章节」串关卡，而非纯刷装。

## 2. 核心循环

| 层级 | 时长 | 流程 |
|---|---|---|
| 微循环 | 30 秒–2 分钟 | 遭遇 → 读招 → 破招/连段 → 清场 → 拾取/开门 → 下一屏 |
| 短循环 | 3–8 分钟 | 场景段 → 战斗/解谜/对话 → 资源 → 回枢纽强化 |
| 中循环 | 一章 25–40 分钟 | 主线/恩怨 → 2–4 横版段 → 精英或 Boss → 人物态度变化 |
| 长循环 | 主线 8–12 小时 | 三幕剧情 + 侠名定型 + ≥3 结局；支线/秘境可再 +4–8 小时 |

## 3. 战斗系统

### 3.1 操作（PC / 手柄）

| 功能 | 键鼠 | 手柄 |
|---|---|---|
| 移动 | WASD | 左摇杆 |
| 冲刺 | Shift | L3 |
| 轻击 | 鼠标左 / J | X / □ |
| 重击 | 鼠标右 / K | Y / △ |
| 技能 1/2/3 | U / I / O | 可自定义 |
| 格挡（按住） | F | LT |
| 弹反 | 格挡开始后的精确帧 | 同上 |
| 闪避 / 轻功 | Space | A / × |
| 轻功上层 | W + 闪避 | 上 + 闪避 |
| 互动 | E | B / ○ |

### 3.2 连段与取消

- 默认连段：轻→轻→轻；轻→轻→重；重可单使。
- 轻击中后段可取消为闪避/技能；重击仅允许技能取消。
- 空中：轻×2 + 下重砸（落地硬直可被惩罚）。

### 3.3 帧意图（调参起点）

| 动作 | 前摇 | 后摇 | 取消窗 | 备注 |
|---|---|---|---|---|
| 轻 1/2 | 短 | 短–中 | 高–中 | 起手与中段 |
| 轻 3 | 中 | 较长 | 低（可进重/技能） | 收招 |
| 重击 | 长 | 长 | 仅技能 | 破防、削霸体 |
| 闪避 | — | 短 | — | 无敌约 8–12 帧 |
| 弹反 | 格挡开始后约 6–10 帧 | — | — | 破招硬直，回内力 |

### 3.4 破招三角

```
        快攻（轻连）
       ／         ＼
 弹反/格挡  ←——→  重击/破防
```

- 敌人蓄力重招 → 闪避或弹反。
- 敌人连斩 → 格挡或重击打断收招。
- 敌人龟缩 → 重击破防，或闪穿绕背。

### 3.5 资源

- **气血：** 归零失败；打药有前摇。
- **内力：** 技能与部分轻功消耗；命中、弹反、击杀回复。
- **敌人架势条：** 被重击/弹反削减；清空可处决或长硬直。玩家默认无架势条。

### 3.6 兵器手感

| 兵器 | 射程 | 速度 | 特长 | 短板 |
|---|---|---|---|---|
| 剑 | 中 | 中 | 弹反容错、连段稳 | 爆发一般 |
| 刀 | 中近 | 快 | 多段、流血 | 破防偏弱 |
| 枪 | 远 | 慢 | 突进、清杂 | 贴身易被摸 |
| 拳/掌 | 近 | 快 | 抓取、内力技 | 对枪劣势 |

同门派可换兵器；**门派核心机制不变**。

### 3.7 敌人分层

| 类型 | AI 意图 | 教学目的 |
|---|---|---|
| 杂兵刀手 | 两招连斩 + 偶冲刺 | 格挡与轻连 |
| 杂兵弓手 | 远端点射 | 优先级与突进 |
| 盾兵 | 高盾 | 重击破防 |
| 精英捕头 | 红甲霸体招 | 等破绽、弹反 |
| 侠客对手 | 近似玩家三连 | 对拼节奏 |
| Boss | 2–3 阶段 | 章节高潮 |

### 3.8 Boss 模板与示例

**模板字段：** 叙事身份 → 阶段 1 招表 → 转阶段演出 → 阶段 2 新机制 → 可学奖励 → 劝降条件。

**示例：血刀门「赤练」**

- 阶段 1：快刀三连、低扫、隔空刀气。
- 转阶段：刀碎改双短刃，场地起火。
- 阶段 2：红甲冲刺（需弹反或闪穿）、甩刃回旋。
- 奖励：刀系心法「血雾」（击杀回微量气血，非战斗回血变慢）。
- 劝降：拥有「济弱」且未滥杀俘虏 → 可收临时助战。

## 4. 门派与技能

### 4.1 青锋剑派 · 剑意

命中叠剑意（最多 5）；满层或弹反触发「剑意绽放」。定位：稳健、教学友好。

| 技能 | 内力 | 效果 |
|---|---|---|
| 破空刺 | 低 | 短突进刺，可取消后摇 |
| 回风舞 | 中 | 身周剑气，清近身 |
| 一剑霜寒 | 高 | 蓄力直线大刺，高破架势 |
| 御剑飞来 / 以剑御气 / 万剑归宗 | 高 | 后期扩展 |

### 4.2 魔刀谷 · 流血 / 刀瘾

攻击叠流血；流血期自身攻击↑、受疗↓。「饮血」引爆流血并自损。定位：高风险高回报。

代表技：鬼影斩、血月、饮血一刀、刀幕、亡命步、魔煞。

### 4.3 落云枪门 · 枪势

空挥/被闪掉势；命中与控场回势。满势「穿云」超远突刺。定位：距离管理与清场。

代表技：苍龙出水、横扫六合、点穴枪、回马、天罡枪阵、穿云。

### 4.4 偷师规则

主线关键节点最多偷 **2** 个外门主动技；外门技内力 +20%，不与本门核心机制协同；UI 标记「外门」。

## 5. 养成与经济

### 5.1 属性

气血、内力、力道（攻击/破架势）、身法（闪避窗/部分暴击）、根骨（减硬直/格挡减伤）。

升级主加气血/内力；力道身法等靠心法与装备。

### 5.2 招式谱与心法

- **招式谱：** 消耗「残页」解锁连段分支与技能机制升级（缩前摇、加段数等），非纯百分比。
- **心法：** 1 主 + 1 辅；主心法定流派，存在互斥。

### 5.3 装备与经济

栏位：武器、衣服、靴、饰品×2、暗器。  
词条分基础 / 战斗 / 江湖三类；江湖词条少而有趣。  
银两来自战斗、任务、贩卖；装备品阶按章节封顶，防通胀。

## 6. 世界与关卡

### 6.1 结构

```
序章：边城客栈 / 灭门现场（教程）
第1章：清河城枢纽 + 官道、竹林、县衙暗道
第2章：雁门边关 + 关墙、驿站、军阵
第3章：南疆或海岛 + 终局决战地
秘境：3–5 个高难横版（独特心法）
```

### 6.2 关卡段必填清单

进出点与检查点｜平台层数与捷径｜敌人编队｜1 个环境互动｜1 个隐藏｜1 个叙事拍点。

### 6.3 示例关：清河城郊「夜奔官道」（约 8–10 分钟）

| 屏 | 内容 |
|---|---|
| 1 | 轻连清刀手；酒坛可踢 |
| 2 | 弓手高台 + 盾兵；教重击破盾 |
| 3 | 屋脊多层轻功；檐后藏残页 |
| 4 | 精英捕头；红甲冲刺教弹反 |
| 5 | 篝火检查点 + 商人短对话 |
| 6 | 竹林迷雾；脚步声提示 |
| 7 | 门神/小 Boss，通关进城 |

解谜只做武侠逻辑（负重石板、射绳、飞檐）；每章 1–2 个。

## 7. 叙事、角色与任务

### 7.1 调性

半文言白话，短句有力；少网络梗。恩怨、承诺、名声优先于「打怪升级」口号。

### 7.2 主角出身差分

| 出身 | 初始标签 | 开场冲突 | 关系修正 |
|---|---|---|---|
| 灭门遗孤 | 济弱 +1 | 「认亲」骗局 | 对无面忌惮更高 |
| 落魄捕快 | 守信 +1 | 「铁证」自保或呈堂 | 沈峥开局熟识 |
| 山贼弃徒 | 诡诈 +1 | 「断义」旧伙索命 | 易搭上阿芒；官军忌惮高 |

### 7.3 侠名标签

| 标签 | 来源 | 解锁 |
|---|---|---|
| 守信 | 履约 | 特殊交易 |
| 济弱 | 救民、放俘虏 | 劝降选项 |
| 嗜杀 | 杀降等 | 魔道路径 |
| 诡诈 | 欺骗任务 | 黑市、反间 |

### 7.4 角色卡（首发 14 人）

**设计原则：** 每人一条「要」与一条「怕」；至少一次站队冲突；可缺席；离开/死亡写入江湖录。

#### 主线枢轴

| 角色 | 要 / 怕 | 弧光要点 |
|---|---|---|
| 周叔（茶馆） | 耳目生意 / 怕连坐封馆 | 可护馆、献金或卖情报；影响任务板 |
| 沈峥（捕快） | 查真凶 / 怕成酷吏 | 可搭档；玩家嗜杀过多将对决 |
| 无面（细作） | 搅局握谱 / 怕真名暴露 | 伪装多人；改写其他任务幕后选项 |
| 北冥先生（终局） | 以杀止杀重定秩序 / 怕被证私仇 | 多形态 Boss；劝降极苛刻 |

#### 门派与武学

| 角色 | 要点 |
|---|---|
| 柳听雪（青锋师傅） | 剑出有名；任务《剑意初成》《耻剑》 |
| 阿芒（魔刀叛逃） | 可同伴可黑化；《刀谷来人》《戒刀七日》《最后一刀》 |

#### 市井与边关

### 7.5 同伴助战

同时 ≤1 人；伤害约玩家 60%；倒地可救；枢纽可嘱咐稳健 / 激进 / 保全。

### 7.6 主线三幕

1. **入江湖（2–3h）：** 灭门/冤案 → 择门派 → 清河立足 → Boss 赤练 → 残谱第一页。  
2. **辨正邪（3–4h）：** 边关与走私 → 正派丑闻 → 站队 → 失去一位重要 NPC → 残谱复合。  
3. **定侠名（3–4h）：** 终局地 → 真凶翻转 → 劝降或处决 → 多结局尾声。

### 7.8 第二、三章节选

**雁门：** 关墙夜｜两封信｜正邪一纸｜谁先落子（失一盟友）｜雁门家书｜戒刀七日｜放粮｜入伙酒｜戴罪立功｜父愿｜军阵鬼影。

**终局：** 残谱合页｜旧皮揭开（无面）｜北冥之问｜最后一刀｜耻剑｜今日开书｜周叔南迁。

### 7.9 结局挂钩

| 条件倾向 | 结局 |
|---|---|
| 高守信 + 两门好感 + 茶馆仍在 | 开宗立派 |
| 高武力评价 + 低门派绑定 | 独行天下 |
| 高济弱 + 拒脏钱 + 放粮成功 | 归隐 |
| 高嗜杀 + 饮血线 + 阿芒黑化 | 堕魔 |
| 与无面合作 ≥2 次 | 隐藏「棋子结局」（灰暗） |

## 8. 难度、进度与 UI

| 模式 | 检查点 | 敌人 | 提示 |
|---|---|---|---|
| 浪客 | 密 | 弱 | 多 |
| 侠客（默认） | 正常 | 正常 | 中 |
| 宗师 | 疏 | 强、少回复 | 少/无 |

死亡回检查点；可轻掉银两（可捡回）；不掉装备。手动存档 + 章节自动存档。

**HUD：** 气血、内力、三技能槽；教学旁白可关；键位全自定义；减少镜头震动等无障碍选项。

## 9. 美术与音频

- **视觉：** 水墨勾边、鲜明剪影；宋元山水意境；刀光水墨溅；宣纸 UI。
- **动画优先：** 主角兵器套 → 杂兵 → 精英+Boss（MVP）→ 扩门派。
- **打击感：** 命中停顿 2–4 帧 + 轻缩放。
- **音频：** 探索丝竹，入战鼓点；剑/刀/枪音色区分。

## 10. 范围、MVP 与排期

### 10.1 技术建议

引擎：Unity / 团结 2022 LTS 或 Godot 4。  
战斗：状态机 + 帧数据表。存档本地。输入支持热插拔。

### 10.2 MVP（8–12 周垂直切片）

1. 青锋剑派单人  
2. 序章 +「夜奔官道」全段  
3. 轻/重/闪/格挡弹反 + 2 技能  
4. 刀手/弓手/盾兵 + 捕头 + Boss 赤练  
5. 简单升级 + 1 把换刀对比  
6. 杀/放分支影响短尾声  

**成功标准：** 外部试玩 10 人中 ≥7 人想再打一关；弹反教学完成率 ≥70%。

### 10.3 完整版目标

3 门派｜主线 8–12 小时｜3 大区域｜≥6 Boss｜≥12 心法｜≥3 结局｜简中完整。

### 10.4 排期草案

| 阶段 | 周期 | 产出 |
|---|---|---|
| 预研 | 2–4 周 | 手感原型、帧数据工具 |
| MVP | 8–12 周 | 可玩切片 |
| 内容生产 1 | 3–4 月 | 第 1–2 章、2 门派 |
| 内容生产 2 | 3–4 月 | 第 3 章、第 3 门派、Boss |
| 打磨 | 6–8 周 | 数值、无障碍、性能、本地化 |

## 11. 风险、指标与待决

| 风险 | 对策 |
|---|---|
| 范围爆炸 | 锁 MVP 门清单 |
| 门派同质 | 每门先做不可替换核心机制演示关 |
| 剧情拖战斗 | 战斗中叙事、对话可跳过 |
| Boss 堆血 | 阶段机制强制评审 |
