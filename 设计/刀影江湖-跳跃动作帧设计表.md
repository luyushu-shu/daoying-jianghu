### 0.1 运动学重力参数参考（Kinematic Parameters）

为达成横版硬核动作的“清脆起落”与国风轻功的“凌空飘逸”，采用**非对称重力曲线**（上升轻灵、峰顶微悬、下落干脆）：

```
           [ J4 滞空顶点 Apex ] (微重力悬停 0.5×g)
               /            \
              /              \  (下坠重力 1.25×g，清脆不拖泥)
   [ J3 凌空拔高 ]             \
         /                    [ J6 破风俯冲 ]
        /                            \
   [ J2 蹬地爆发 ]                    \
      |                               [ J7/J8 屈膝触地缓冲 4f ]
   [ J1 屈膝蓄势 3f ]
════════════════════════════════════════════════════════════ 地面
```

- **角色身高基准**：1 身 = 1.4 世界单位（`KinematicBody2D.size = (0.7, 1.4)`）。
- **起跳初速度**：$V_{y0} \approx +15.5\ \text{单位/秒}$。
- **上升重力**：$g_{up} \approx -38.0\ \text{单位/秒}^2$。
- **顶点微悬浮窗（Apex Hang）**：当 $|V_y| \le 2.0\ \text{单位/秒}$ 时，重力削减为 $0.5 \times g_{up}$（约 4~6 帧微滞空，给玩家从容派生空中出招或空闪的绝佳手感）。
- **下落重力**：$g_{down} \approx -48.0\ \text{单位/秒}^2$（下落略快于上升，避免“气球感/漂浮感”）。
- **最大下落终端速度**：$V_{max\_fall} = -20.0\ \text{单位/秒}$。

### 0.2 现代手感保障机制（Feel Mechanics）

1. **土狼时间（Coyote Time · 5f ≈ 83ms）**：角色跑出悬崖或断层离开地面的前 5 帧内按下跳跃，仍然判定为地面合法起跳。
2. **跳跃预输入缓冲（Jump Buffer · 6f ≈ 100ms）**：在角色下落即将着地前的 6 帧内按下跳跃，落地第 0 帧自动无缝执行下一次起跳。
3. **可变跳跃高度（Variable Jump Height）**：在 J1~J3 阶段若松开跳跃键，立即提前截断垂直速度（垂直速度衰减为当前的 0.55×），实现精准利落的小跳压制。
4. **低盘受击框抬升（Low-Profile Hurtbox）**：起跳离地当帧起，角色脚底至膝盖下部的受击判定盒收起，**完全免疫地面波、地刺与 Boss 的低扫招式**（如赤练的 `B_CL_SWEEP`）。

## 3. 空中战斗派生与取消规则（Air Combat & Cancels）

跳跃不是单纯的位移，更是立体空战的起点。青锋剑客在腾空期间享有完整的招式派生链：

```
                    ┌── 空中轻击一段 A_AL1 (凌空平斩) ──> 空中轻击二段 A_AL2 (旋身回锋)
                    │
[ J2~J6 空中自由态 ] ├── 空中下重砸 A_AD (千斤坠·惊雷裂地，直插下砸，落地带震波与 12f 硬直)
                    │
                    ├── 空中闪避 MOV-AIRDODGE (提气踏风，向前/后破空 0.8 身，带 3-11f 无敌)
                    │
                    └── 轻功二段·踏燕 (二段跳，脚底炸裂青莲剑气，再次跃升 1.5 身)
```

### 3.1 招式派生细节与帧连接

1. **空中轻击 1/2（A_AL1 / A_AL2）**：
   - 允许在 J3（上升中后段）至 J6（下落中段）任意帧按 `J`（或鼠标左键）触发。
   - **空中平水悬浮机制**：出剑瞬间重力暂时锁死 4f，挥出利落弧月剑芒，下落速度清零，保证空战连击不会因急坠而打空。
   - 空中打完一段后可在 8–14f 窗口内接续空中轻击二段或空闪。
   - 若出招未结束即触地：触发 **空中着地硬直 8f**（取消挥剑后摇，转入踏地收剑动作）。

2. **空中下重砸（A_AD 千斤坠·破空下劈）**：
   - 空中按 `下 + 重击（S + K 或 S + 鼠标右键）`。
   - Startup 10f：角色在空中收剑抱元、凌空翻身 180°；
   - Active：化作一道青白长虹笔直以极速（$-28.0\ \text{单位/秒}$）俯冲直插地面；
   - 触地：地面炸开长径 2.0 身的水墨震地剑气波，造成高额架势伤害；自身进入 **12f 不可取消落地硬直**（高风险高回报）。

3. **空中闪避（MOV-AIRDODGE）**：
   - 空中任意非受击状态下按 `Space`（闪避）。
   - 消耗单次跳跃内的唯一空闪配额；
   - 角色身体幻化为 2~3 重水墨虚影，水平穿刺 0.8 身；
   - 无敌帧：3–11f（9 帧）；落地后额外追加 4f 硬直。

4. **落地硬直取消特权（Landing Cancel）**：
   - 自然落地（J7/J8）的 4 帧缓冲中，**允许第 1 帧直接输入闪避（Space）或轻击（J）提前打断**，实现行云流水的“踏地反斩”或“着陆滑闪”。

## 4. 美术规格与切片方案（Art Direction & Slice Setup）

### 4.1 画布与像素对齐规范

为了与现有的 `Idle`、`Run`、`Dodge`、`Attack` 完全无缝共存，跳跃序列严格遵循全套工程规范：

- **基准画布尺寸**：**$680 \times 480\ \text{px}$**。
- **人物基准站高**：立正身高 **$328\ \text{px}$**。
- **PPU（Pixels Per Unit）**：严格为 **$214.0$**（即 $328\text{px} / 214 \approx 1.53\ \text{单位}$，与全工程 1.4~1.5 单位身高完美吻合）。
- **轴心（Pivot Point）**：自定义脚底中心 **$(X=0.5, Y=0.09)$**（即底部上浮 43px 处为实际地面接触基线 $Y=437\text{px}$）。
- **色彩与边缘纯净度**：Despill 消除洋红色溢色，保持青绿外袍（#2C6D58 附近）与雪白衬袍、墨黑发饰的层次分明。

### 4.2 引擎切片与 Animator 组织架构（3 种常用切片方案）

根据工程实现灵活度，推荐采用 **方案 A（经典 4 段式切片）**，兼具手感即时响应与动画表现力：

```
                    ┌─── [Jump_Up] (上升段：J1~J3，3+2 关键帧) ──> 速度 > 1.5
                    │
[Locomotion 地面] ───┼─── [Jump_Apex] (顶点过渡：J4，2 关键帧) ───> 速度在 -1.5~1.5 之间
                    │
                    ├─── [Jump_Fall] (下落段：J5~J6，2 关键帧循环) ──> 速度 < -1.5
                    │
                    └─── [Jump_Land] (落地缓冲：J7~J8，2 关键帧非循环) ──> 触地触发，0.06s 切回 Idle/Run
```

- **方案 A（4 状态分切 · 推荐）**：
  1. `PlayerJumpUp`：起跳深蹲 + 向上跃升（单次播放或停在上升最高帧）；
  2. `PlayerJumpApex`：悬停微调帧（当 `Mathf.Abs(vel.y) < 1.5` 时播放）；
  3. `PlayerJumpFall`：下落急坠帧（下落时保持或循环微动）；
  4. `PlayerJumpLand`：触地卸力（单次 4f 播放后立即退出）。
- **方案 B（连续 8 帧单切片）**：
  - 适合预览场景与轻量化状态机：制作单一完整的 `PlayerJump.anim`（总长 8 帧，约 0.45s），在空中依时间或垂直速度曲线采样。

## 5. 状态机与代码集成建议（Unity / 团结引擎）

在 `SpriteAnimSetup.cs` 和 `PlayerSpriteLocomotion.cs` 中增加跳跃支持的清晰规范：

### 5.1 Animator Controller 参数增补

- `IsGrounded` (Bool)：是否处于地面。
- `VerticalSpeed` (Float)：垂直速度（用于 JumpUp ↔ JumpFall 的混合或过渡）。
- `Jump` (Trigger)：起跳触发器（AnyState / Grounded → JumpUp）。
- `Land` (Trigger)：触地触发器（JumpFall → JumpLand）。

### 5.2 状态机过渡条件设计

| 源状态 | 目标状态 | 条件 | Exit Time | Duration |
|---|---|---|---|---|
| AnyState / Grounded | JumpUp | `Jump` Trigger | 无 | 0.02s |
| JumpUp | JumpFall | `VerticalSpeed < -0.5` 且 `!IsGrounded` | 无 | 0.05s |
| JumpFall | JumpLand | `IsGrounded == true` 或 `Land` Trigger | 无 | 0.01s |
| JumpLand | Idle | `Has Exit Time` (0.95) 或 `Speed < 0.1` | 有 (0.92) | 0.04s |
| JumpLand | Walk / Run | `Speed > 0.1` (提前打断) | 无 | 0.02s |
