## 0. 读表说明

### 0.1 字段定义

| 字段 | 含义 |
|---|---|
| 前摇 Startup | 从输入受理到**首段判定出现**的帧数 |
| 判定 Active | 攻击盒存在的帧数（可分段记 Active1/2…） |
| 后摇 Recovery | 判定结束后到恢复站立／可行动的帧数 |
| 总长 Total | Startup + Active + Recovery（不含落地另计） |
| 取消窗 Cancel | 可取消到闪避／技能／下一轻的帧区间（相对本招第 0 帧） |
| 硬直给敌 Hitstun | 命中普通敌人造成的受击硬直帧 |
| 架势伤 Poise | 对敌人架势条的削减值（相对） |
| 自身硬直 Blockstun | 被格挡时攻击方剩余后摇修正（可选） |
| 无敌 I-Frames | 无敌起始–结束帧 |
| 位移 | 像素或「身长」单位；+为向面朝方向 |
| 内力 | 消耗；负值表示回复 |

### 0.2 取消规则（全局）

| 来源 | 可取消到 | 条件 |
|---|---|---|
| 轻1／轻2 | 轻下一／闪避／技能／重（仅轻2末） | 取消窗内 |
| 轻3 | 重／技能／闪避（窗短） | 取消窗内 |
| 重 | **仅技能** | 取消窗内 |
| 技能 | 默认不可取消（另注） | — |
| 闪避 | 落地后 4f 起可攻击 | — |
| 受击 | 不可取消 | — |

### 0.3 通用手感参数

| 参数 | v0.1 值 | 备注 |
|---|---|---|
| 命中停顿 Hitstop（轻） | 双方 2f | 可关无障碍 |
| 命中停顿（重） | 双方 4f | — |
| 命中停顿（技能） | 3–5f | 技能表另注 |
| 弹反成功世界时缓 | 60% × 8f | 可关 |
