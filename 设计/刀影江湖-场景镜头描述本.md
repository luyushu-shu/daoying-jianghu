# 《刀影江湖》场景镜头描述本

| 项 | 内容 |
|---|---|
| 用途 | 过场／演出／分镜／概念图对齐；可给动画与关卡演出用 |
| 对齐 | `刀影江湖-剧情对白旁白全本.md`、场景地图概念图 |
| 标注 | **镜号**｜景别｜机位／运动｜画面｜声音｜时长｜对白锚点 |
| 景别缩写 | 大远／远／全／中／近／特／大特；主观＝POV |

### 读法

- **横版游玩段**：镜头以「虚拟摄影机跟随」为主，表中写清锁定、拉远、震屏、切入特写时机。  
- **过场 CG／立绘对话**：按传统分镜写死。  
- 时长为建议秒数，可按语速伸缩。

| 月下／雪夜 | 高对比边缘光；粒子雪／火星分层在前景 |
