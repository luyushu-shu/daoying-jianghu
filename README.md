# 刀影江湖 (Blade Shadows: Jianghu)

> **水墨国风硬派 2D 横版武侠动作游戏 · 纯运动学物理实机战斗原型**

《刀影江湖》是一款水墨国风硬派写实风格的 2D 横版动作游戏。核心战斗设计秉持 **“严谨帧数据、刀刀入肉、架势破绽、精准招架、剑意绽放”** 的理念，融入中国传统武术套路与冷兵器碰撞的沉浸打击感。

## 一、 实机战斗原型场景

实机战斗场景：**`New Tuanjie Project/Assets/Scenes/CombatPrototype.unity`**  
动作与技能独立预览场景：**`New Tuanjie Project/Assets/Scenes/SpritePreview.unity`**

* **双角色与技能完整接入**：
  * **青锋剑客（玩家）**：12 个基础动作 + 破空刺（常态与剑意绽放双形态）全链路无缝流转，涵盖地面机动、空中机动、轻连三段、蓄力重刺、三段防御弹反与剑意绝技。
  * **杂兵刀手（AI 敌人）**：基于真实视频扣帧精雕的 8 帧持刀呼吸待机循环、15 帧同步巡逻行步、近战横斩蓄力突袭。
* **纯运动学物理对地吸附（彻底解决“卡脚”/打滑）**：
  * 基于 `KinematicBody2D` 运动学底座，采用贴合足底的向下盒形扫掠（$y=+0.15$ 向下检测 $0.20 - dy$），确保角色移动与站立时绝对稳固贴地，杜绝微悬空误判与伪落地硬直抖动。
* **高打击感顿挫机制**：
  * 全局固定 60FPS 逻辑帧，融合 **顿帧（Hitstop 2~8 帧）**、**时空慢放（Chrono Pause / SlowMo）**、**全屏水墨震颤** 与受击后退卸力。
  * 命中敌兵显示伤害飘字；精准弹反触发金色“弹反!”暴击星芒并强制打断敌招，赋予 28 帧追击破绽。

## 六、 技术架构与工程入口

* **开发引擎**：团结引擎 (Tuanjie) 2022.3 LTS
* **代码目录结构**：
  * `Assets/Scripts/Combat/`：战斗核心机能（`CombatActor.cs` 角色实体、`States.cs` 状态机与连段链、`KinematicBody2D.cs` 运动学物理、`CombatDirector.cs` 顿帧与慢放指挥）
  * `Assets/Scripts/Player/`：
    * `PlayerBrain.cs`：实机战斗输入缓冲与连击驱动
    * `PlayerSpriteLocomotion.cs`：`SpritePreview` 交互测试器（WASD、J/K、Q/U、E/O、I，带 OnGUI 触控面板）
    * `PokongciBloomFX.cs`：**极·破空刺电影级特效驱动系统**（程序化生成星芒、冲击波、光锥、飞剑、空间裂纹、地表霜痕与相机震颤）
    * `CharacterFootskateFix.cs`：防滑步脚跟速度动态补偿器
  * `Assets/Scripts/Enemy/`：敌人行为树与状态控制（`SwordsmanBrain.cs`、`MookPreviewActor.cs`）
  * `Assets/Scripts/Core/`：主逻辑引导与战斗场地灰盒搭建（`GameBootstrap.cs`）
* **自动化资产与图像管线** (`scripts/`)：
  * [clean_sprites.py](scripts/clean_sprites.py)：洋红纯底全自动去杂色、抗锯齿羽化、透明 PNG 与 GIF 导出管线。
  * [process_yijianshuanghan_sheet.py](scripts/process_yijianshuanghan_sheet.py)：一剑霜寒常态版母图切片、255色调色板无黑影GIF导出与Unity精灵.meta注入。
  * [process_yijianshuanghan_bloom_sheet.py](scripts/process_yijianshuanghan_bloom_sheet.py)：一剑霜寒剑意绽放强化版（冰魄玄峰）母图切片、足底锁定Y=437、255色全彩GIF导出与Unity精灵.meta注入。
  * [rebuild_all_controllers.py](scripts/rebuild_all_controllers.py)：自动化构建控制器状态机。
  * [build_mook_unity_anims.py](scripts/build_mook_unity_anims.py)：根据动作序列生成 Unity 动画片段。
